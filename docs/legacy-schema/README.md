# Historical schema archive

`mysql-schema.sql` is an obsolete historical artifact, not an installation source.
It was moved out of Laravel's automatically loaded `database/schema` directory.
Do not import it, move it back, or use it to mark migrations as completed.

The authoritative installation path is the dependency-ordered Laravel migrations.
See `../MICA_DEMO_DATABASE_SETUP.md` for the guarded fictional demo seed/reset path.
